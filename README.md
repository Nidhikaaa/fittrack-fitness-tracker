# FITTRACK – Gym & Fitness Tracker

FITTRACK is a fitness tracking website designed to help users monitor their daily workout activities, track water intake, and maintain consistency in their fitness journey.

## Features
- Workout categories
- Daily workout tracking
- Water intake tracking
- Fitness streak tracking
- Progress monitoring
- Interactive user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

## Getting Started
1. Download or clone this repository.
2. Open `fittrack.html` in your web browser.
3. Start exploring FITTRACK!
